# ATM-SIMULATOR-SYSTEM

# GUI Banking System in Python

A desktop application built using Python and `tkinter` that simulates core banking functions including account creation, secure login, real-time balance updates, deposits, withdrawals, and persistent JSON transaction logging.

## Features

- **Account Management**: Auto-generate unique account numbers with 4-digit PIN protection.
- **Transaction Processing**: Perform deposits and withdrawals with real-time balance updates.
- **Transaction History**: Track recent activity per account.
- **Data Persistence**: Save account state locally in JSON format.
- **Unit Tested**: Core domain logic and storage engines are fully covered using `unittest`.
